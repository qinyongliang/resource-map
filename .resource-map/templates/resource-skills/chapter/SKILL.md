# Chapter Resource Skill Template

One chapter resource owns the complete chapter Markdown body. Read the whole chapter before extracting a concise synopsis, scene transitions, participants, state changes, explicit reveals, conflicts and unresolved clues. Add stable block IDs to the exact evidence paragraphs used by graph edges. A chapter is not duplicated as chapter-resource or binding.
## 安全边界

默认仅允许有界只读探测。禁止输出凭证、完整环境变量、私钥、业务行、消息正文或缓存值。重启、部署、写配置、写 SQL、清理、扩缩容、故障转移和凭证变更必须先获得用户明确授权。
